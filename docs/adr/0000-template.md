# NNNN. Title in a few words

- **Status:** proposed | accepted | superseded by NNNN
- **Date:** YYYY-MM-DD
- **Rules:** the spec rules this changes or relies on, such as D-4 or P-11

## Context

What forces the decision: the problem, the constraints, and what the spec says today.

## Decision

What we do, stated so that a reviewer can check an implementation against it.

## Consequences

What becomes easier or harder, what is now a contract, and what a later change would cost.

## Alternatives considered

Each option we rejected, and why.
