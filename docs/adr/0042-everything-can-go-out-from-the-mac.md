# 0042. Releases can go out from a maintainer's machine

- **Status:** accepted, amended by [0064](0064-the-source-lives-here.md): releases build in this
  repository's CI, and a maintainer's machine is the fallback
- **Date:** 2026-11-01

Internal release infrastructure: a release can be built, checked and published from a
maintainer's machine as well as from CI. It changes nothing about the CLI's behavior, so its text
isn't published.
