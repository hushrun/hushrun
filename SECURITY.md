# Security

Please don't report security problems in public issues.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/hushrun/hushrun/security/advisories/new), or
by email to support@hushrun.com with "security" in the subject. We'll acknowledge the report
within three working days and keep you updated until it's fixed.

Only the newest release gets security fixes. `hushrun update` installs it.
